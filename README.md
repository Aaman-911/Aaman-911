### 🚀 Featured Projects

**[🛡️ WATCHER: Prompt-Injection Defence for Browsing Agents](https://github.com/Aaman-911/watcher)**<br>
A zero-dependency defence library, a hardened browsing agent and a Chrome extension. Deterministic detection flagged 18/18 adversarial runs with 0 false positives on matched clean pages, backed by 22 test suites and CI on every push.<br>
`Node.js` `Chrome MV3` `LLM agents` `GitHub Actions`

**[🤟 SANKET: Two-way Indian Sign Language Terminal](https://github.com/Aaman-911/SANKET-HACKSYNAPSE)** 🏆 *Hackathon winner*<br>
A deaf visitor signs, staff read text, staff reply, and a 3D avatar signs it back. Each camera frame becomes 543 landmarks, classified on-device by a BiGRU trained on 4,800 self-recorded clips.<br>
`TypeScript` `React` `TensorFlow.js` `ONNX Runtime Web` `MediaPipe` `Three.js`

**[✨ Mark Killer: Gemini Watermark Remover for Chrome](https://github.com/Aaman-911/mark-killer)**<br>
Reverses Gemini's visible watermark blend exactly, for images and for Veo video decoded and re-encoded locally with WebCodecs. Nothing ever leaves the browser.<br>
`JavaScript` `Chrome MV3` `WebCodecs` `OffscreenCanvas`

**[🎙️ HireUS: AI Mock Interviewer](https://github.com/Aaman-911/hireus)**<br>
Adaptive questions for your role and level, voice or typed answers, a Gemini-scored report on four metrics, and live job matches from Adzuna.<br>
`React 19` `Express 5` `Gemini API` `Web Speech API`
